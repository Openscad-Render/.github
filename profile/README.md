## Core OpenSCAD Features

- **A Script:** The model is text you write: cubes, cylinders, and the numbers that size them.
- **A Preview:** Render the script to see the solid. A syntax error is a line you can read, not a mystery mesh.
- **Export:** Write an STL or another mesh when a printer or a viewer needs a frozen shape. Keep the script as the file you edit.
- **Parameters:** Change a width in one place and render again, instead of dragging a vertex you cannot measure.

---

## About OpenSCAD

OpenSCAD is for parts you describe yourself. A bracket, a box, or a simple enclosure becomes a script with dimensions you chose. It does not include a store of commercial models, and a mesh you do not have rights to is not a script you should claim as your design.

The script is the source. The STL is an export. If the print is the wrong size, you change the number and export again. You do not push vertices in the STL and hope the next version matches. Save the script before a long render. A preview that looks right and was never saved is easy to lose.

Start with one solid and one dimension you can check with a ruler or a known size. Assemblies of many parts are easier after a single file renders and exports.

## Getting Started with OpenSCAD

Prerequisites: A folder for the script, and a size you already decided.

1. **Write a Simple Solid:** A cube or cylinder with a dimension you can check.
2. **Preview It:** Fix errors in the text before you export.
3. **Save the Script:** Use a name that says what the part is.
4. **Export a Mesh:** Open it only to confirm. Do the next edit in the script.

## Professional & Personal Use Cases

- **A Printed Bracket:** Change one number when the hole is too tight, then export again.
- **A Repeatable Box:** The same script with a different height for the next version.
- **A File You Can Diff:** The model is text, so two versions can be compared as text.
- **A Spare:** Keep the script. The STL alone is harder to revise.
